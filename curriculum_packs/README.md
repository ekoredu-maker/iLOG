# 지도계획 데이터팩

아이로그는 두 종류의 지도계획을 함께 사용할 수 있습니다.

## 1. 국가수준 기본안

`backend/national_curriculum.py`에 2022 개정 교육과정의 영역·내용체계를 바탕으로 한
**1~6학년 출판사 독립형 기본 지도내용**이 탑재됩니다.

- 특정 출판사의 교과서·지도서 문장을 복제하지 않습니다.
- 학교의 실제 연간시간표에서 만들어진 과목별 차시 수에 맞춰 자동 확장됩니다.
- 교사는 적용 후 채택 교과서, 학교교육과정, 학생 수준에 맞게 단원·학습목표·지도내용을 자유롭게 수정할 수 있습니다.
- 국가수준 기본안의 성취기준 문장은 원문 코드/문장의 복제본이 아니라 교육과정 내용체계를 바탕으로 한 요약·재구성 자료입니다.

## 2. 학교·교사·출판사별 데이터팩

이 폴더의 `*.json` 파일은 프로그램에 함께 묶여 배포되며 지도계획 라이브러리에 `기본 탑재`로 표시됩니다.
교사가 직접 가져온 팩은 개인 데이터베이스에 저장됩니다.

### 만드는 방법

1. 프로그램의 [작성 서식 받기]로 받은 엑셀에 내용을 채웁니다.
   - 학년, 과목, 출판사/출처, 학기, 차시, 영역, 단원, 성취기준, 학습목표, 지도내용, 교육과정
2. 변환: `python tools/build_pack.py 입력.xlsx curriculum_packs/`
3. 프로그램을 다시 빌드하면 기본 탑재 데이터로 함께 포함됩니다.

## 저작권 주의

출판사의 지도서·연간지도계획 내용은 출판사 저작물일 수 있습니다.
프로그램에 넣어 배포하려면 필요한 이용 허락을 확인하세요.
허락이 없는 자료는 교사가 자신이 보유한 자료를 [가져오기]로 넣어 개인적으로 사용하는 방식이 안전합니다.
