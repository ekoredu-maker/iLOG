# 기본 탑재 지도계획 데이터팩

이 폴더의 `*.json` 파일은 프로그램에 함께 묶여 배포되며, 교사 화면의
[출판사별 지도계획 라이브러리]에 "기본 탑재"로 표시됩니다.

## 만드는 방법
1. 프로그램의 [작성 서식 받기]로 받은 엑셀에 내용을 채웁니다.
   (학년, 과목, 출판사, 학기, 차시, 단원, 학습목표, 지도내용, 교육과정)
2. 변환: `python tools/build_pack.py 입력.xlsx curriculum_packs/`
   → (학년·과목·출판사)별 JSON 파일이 생성됩니다.
3. exe 를 다시 빌드하면 함께 포함됩니다.

## 주의
- 출판사의 지도서·연간지도계획 내용은 출판사 저작물입니다.
  프로그램에 넣어 배포하려면 해당 출판사의 이용 허락을 받으세요.
  허락이 없으면 교사가 각자 가진 자료를 [가져오기]로 넣어 쓰는 방식만 사용하세요.
- `_sample_g3_math.json` 은 기능 시험용 예시입니다. 배포 전에 지우세요.
