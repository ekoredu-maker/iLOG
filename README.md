# 아이로그 iLOG v10.2 — 초등담임 학급통합관리

Copyright 2026@박주가리교감

v9.x(HTML + Electron)의 화면은 그대로 쓰고, **데이터 저장과 서식 출력을 파이썬**이 맡도록 바꾼 버전입니다.

```
화면(web/: HTML·JS·Bootstrap)  ──pywebview──▶  파이썬(backend/)
                                                 ├─ db.py          SQLite 저장(AES-256 암호화), 백업/복구, 복구 코드
                                                 ├─ attendance.py  나이스 기준 출결 집계, 체험학습 출석인정 연동
                                                 ├─ api.py         화면에서 부르는 기능 모음
                                                 ├─ excel_io.py    엑셀 읽기(날짜 자동 정리)·작성 서식
                                                 ├─ reports.py     엑셀/A4 인쇄용 출력
                                                 ├─ forms.py       학교 서식(체험학습·결석신고서·주간학습안내·가정통지표)
                                                 ├─ hwpx_builder.py 한글(HWPX) 만들기·학교 양식 채우기
                                                 └─ curriculum.py  출판사별 지도계획 라이브러리
```

## 선생님용 안내

### 처음 설치 / 예전 버전에서 옮기기
1. **예전 버전(v9.x)** 에서 [데이터관리 → 백업(JSON) 다운로드].
2. 새 버전을 실행하고 초기 비밀번호 `1234` 로 로그인 → **새 비밀번호를 정합니다**(필수).
3. 화면에 나오는 **복구 코드**를 종이에 적어 보관합니다. 비밀번호를 잊었을 때 이 코드가 유일한 복구 수단입니다.
4. [데이터관리 → 복구]에서 1번 파일을 선택하고 [실행]. (새로 정한 비밀번호는 그대로 유지됩니다)

### 개인정보 보호 (v10.1)
- 학생 이름·연락처·상담·사안 등 **모든 기록이 비밀번호로 암호화**되어 저장됩니다.
  데이터 파일(`ilog.db`)이나 백업 파일을 복사해 가도 비밀번호 없이는 내용을 볼 수 없습니다.
- 비밀번호를 잊으면: 로그인 화면 [비밀번호를 잊었어요] → 복구 코드 입력 → 새 비밀번호.
- 복구 코드를 잃어버렸으면: [기본설정 → 복구 코드 새로 발급] (현재 비밀번호 필요).
- **비밀번호와 복구 코드를 모두 잃으면 기록을 되살릴 수 없습니다.** (개발자도 열 수 없습니다)
- 다른 PC로 옮길 때: 백업 파일 + 백업 당시 비밀번호(또는 복구 코드)가 있으면 됩니다.

### 출결 (나이스 기준)
- 결석·지각·조퇴·결과마다 **질병 / 미인정 / 기타 / 출석인정**을 고릅니다.
- 교외체험학습을 **승인**하면 기간 중 수업일이 자동으로 **출석인정**으로 기록됩니다. 승인 취소·삭제 시 자동으로 지워집니다.
- [통계/기록 → 나이스 출결 통계]: 월별·학기별·학년 전체 시트로 된 엑셀. 월말 출결 마감 때 그대로 보고 입력하면 됩니다.
- 예전 버전 출결 기록은 사유가 없어 '미분류'로 표시됩니다. 출결 창에서 사유를 골라 다시 저장하세요.

### 서식 출력 (v10.2) — [서식 출력] 메뉴
| 서식 | 자동으로 들어가는 내용 | 형식 |
|---|---|---|
| 주간학습안내 | 요일별 교시·과목·학습내용(연간 시간표), 학교 행사·휴업일, 주차 | 한글 / 인쇄(A4 가로) |
| 가정통지표 | 학기 출결(나이스 기준), 학기 평가 결과·관찰 내용, 종합 의견, '가정에서 보내는 글' | 한글 / 인쇄 (학생별 1쪽, 전체 한 번에) |
| 결석·지각·조퇴·결과 신고서 | 이어진 결석일을 묶은 기간, 구분·사유(질병/미인정/기타/출석인정), 증빙 안내. 미인정·기타는 '학부모 확인서' | 한글 / 인쇄 |
| 교외체험학습 신청서·결과보고서·승인(불허) 통보서 | 기간과 수업일수, 올해 사용·허용·잔여 일수, 학습형태, 목적지, 보호자·인솔자, 보고서 제출 기한 | 한글 / 인쇄 |

- **학교 양식 그대로 쓰기:** [학교 양식 등록]에 학교의 한글 파일(.hwp/.hwpx)을 올리면 그 양식에 값을 채워 줍니다.
  - 표의 제목 칸(성명, 목적지, 보호자 성명 등) 오른쪽 **빈 칸**을 자동으로 채웁니다. 인쇄된 글자는 덮어쓰지 않습니다.
  - 원하는 자리에 `{{이름}}`, `{{기간}}` 처럼 적어 두면 그 자리에 들어갑니다. 쓸 수 있는 이름은 화면의 '쓸 수 있는 자리표시'를 보세요.
  - 등록한 양식은 백업 파일에 함께 들어갑니다.
- **서식용 학교 정보:** [기본설정]에 학교장 성명, 체험학습 허용 일수(국내/국외), 신청·보고서·결석신고서 제출 기한을 학칙에 맞게 넣어 주세요.
- **서식 항목의 근거:** 여러 학교 홈페이지와 교육청 지침(예: 경기도교육청 「2025 학교장허가 교외체험학습 운영 지침」)에 공개된 양식에서 공통 항목을 정리했습니다.
  허용 일수, 제출 기한, 증빙 기준은 학교마다 다르므로 설정값과 학교 양식을 우선합니다.

### 기타 설정
- [기본설정]에서 하루 교시 수(4~8교시)와 평가 척도(예: 잘함, 보통, 노력요함)를 바꿀 수 있습니다.
- [데이터관리 → 추가 백업 위치]에 USB·NAS·클라우드 동기화 폴더를 지정하면 자동 백업이 그곳에도 저장됩니다(암호화됨).

### 데이터 위치와 자동 백업
- 데이터 위치: `%APPDATA%\iLOG\ilog.db`. 프로그램을 새 버전으로 바꿔도 이 위치는 그대로입니다.
- 자동 백업: 로그인할 때 하루 한 번 `%APPDATA%\iLOG\backups` 에 저장되며(암호화), 최근 30일치를 보관합니다.
  [복구]와 [전체 삭제]를 실행하기 직전에도 자동으로 백업합니다.

### 출판사별 지도계획
1. [기본설정]에서 학기 기간을 저장하고, [교육과정운영]에서 주간 시간표를 저장합니다.
2. [연간활동관리 → 자동 생성]으로 연간 시간표를 만듭니다.
3. [출판사별 지도계획 불러오기]에서 과목마다 출판사를 고르고 [적용]을 누릅니다.
   - 1학기 차시는 1학기 수업 칸에, 2학기 차시는 2학기 수업 칸에 날짜·교시 순으로 들어갑니다.
   - 미리보기에서 "수업 칸 수 / 차시 수"를 비교할 수 있습니다. 차시가 남거나 빈 칸이 생기면 표시됩니다.
   - 연간 시간표를 다시 생성해도 이미 들어간 지도내용은 유지됩니다.
4. 목록에 없는 출판사 자료는 [작성 서식 받기]로 받은 엑셀에 채워 [가져오기]로 넣습니다.

### 출력
| 출력물 | 위치 | 형식 |
|---|---|---|
| 과목별 연간 지도계획 | 연간활동관리 | 인쇄/PDF(A4 가로), 엑셀(과목별 시트) |
| 종합 학급경영록 | 데이터관리 | 인쇄/PDF(A4), 엑셀(항목별 시트), 사안 기록 포함 여부 선택 |
| 평가 결과 | 학생평가관리 | 엑셀 |
| 학생 개인 종합 기록 | 통계/기록 | 인쇄/PDF |

- 인쇄/PDF를 누르면 Edge 등 기본 브라우저에 A4 서식이 열립니다. 거기서 [인쇄]를 누르고, PDF가 필요하면 프린터를 'PDF로 저장'으로 고릅니다.
- 엑셀 출력물은 A4 용지, 머리행 반복, 쪽 번호가 미리 설정되어 있어 그대로 인쇄할 수 있습니다.

## 개발자용

```bash
pip install -r requirements-dev.txt
python -m pytest -q            # 백엔드 테스트 (암호화·출결·출력 포함)
python tests/e2e_ui.py         # 화면 전체 흐름 자동 점검 (playwright 필요)
python devserver.py            # 브라우저에서 화면 확인: http://127.0.0.1:8765 (데이터: ~/.ilog)
python main.py                 # 데스크톱 창으로 실행 (Windows: Edge WebView2 필요)
```

### exe 만들기
- **직접 빌드:** Windows에서 `build.bat` → `dist\iLOG.exe`(1개 파일) 와 `dist\iLOG_folder.zip`(폴더형).
  학교 배포는 **폴더형을 권장**합니다. 1개 파일형보다 백신(V3·알약 등) 오탐이 적고 시작이 빠릅니다.
- **GitHub에서 자동 빌드:** 이 폴더를 저장소에 올린 뒤 `v10.0.0` 같은 태그를 push 하면,
  Actions가 테스트 → 화면 자동 점검 → exe 빌드 → **실제 창을 띄워 실행 점검** → 릴리스 첨부까지 자동으로 처리합니다.
  Actions 탭에서 수동으로 실행할 수도 있습니다.
- **화면 엔진:** Windows 10/11에는 대부분 WebView2가 이미 설치되어 있습니다.
  없으면 실행할 때 설치 안내 창이 뜹니다.

## v10 변경 사항 (v9.6 대비)
- 저장소를 IndexedDB에서 SQLite로 바꾸고, 데이터 위치를 고정했습니다. 이제 버전을 올려도 데이터가 사라지지 않습니다.
- 하루 한 번 자동 백업하고, 복구·삭제 직전에도 백업합니다.
- 비밀번호를 해시로 저장합니다. 예전 백업을 복구하면 자동으로 해시로 바뀝니다.
- Bootstrap·달력·아이콘을 프로그램 안에 넣어, 인터넷이 끊기거나 CDN이 차단돼도 동작합니다.
- 새 기능: 출판사별 지도계획 라이브러리. 학년·과목·출판사별로 고른 뒤 연간 시간표에 자동 배치합니다.
- 서식 출력: A4 인쇄용 문서와 엑셀 출력을 새로 만들었습니다. 이전에는 화면 일부만 인쇄되거나 표가 잘렸습니다.
- 버그 수정
  - 처음 설치한 상태에서 연간 시간표 생성 시 오류가 나던 문제
  - 연간 시간표를 다시 생성하면 입력한 지도내용이 지워지던 문제
  - 엑셀 일괄 등록 시 ID가 겹쳐 학생·일정이 빠지던 문제. 같은 번호는 이제 갱신됩니다.
  - 교외체험학습을 수정하면 유형이 사라지던 문제
  - 우클릭·스케줄러에서 평가를 추가할 때 과목이 선택되지 않던 문제
  - 지도계획 엑셀의 날짜 형식(2026.3.2 등)을 인식하지 못하던 문제
  - 결석을 출석으로 정정해도 다른 교시의 결석이 남던 문제
  - 사안을 저장·삭제하면 로그아웃되던 문제
  - 체험학습 학생 목록이 갱신되지 않던 문제
  - 이름에 `'` 나 `<` 가 있으면 버튼이 동작하지 않던 문제
  - 달력이 영어로 표시되던 문제
  - 잘못된 백업 파일로 복구할 때 아무 안내가 없던 문제
- 학사일정 목록에서 개별 일정을 삭제할 수 있습니다.
